# 🏛️ 정책사업 사전검토 보고서 자동 생성 시스템

> **고양특례시 · Claude AI 기반 행정혁신 POC**

고양특례시 정책사업의 의회 심의 사전검토를 자동화하는 웹 애플리케이션입니다.
담당자가 사업명·예산·기간 등 기본 정보만 입력하면, Claude AI가 외부 데이터(타 지자체 사례·관련 법령)를 실시간으로 수집·분석하여 **6개 섹션으로 구성된 정책 검토 원페이퍼 보고서**를 자동 생성합니다.

기존에 담당자가 수 시간에서 수일에 걸쳐 작성하던 사전검토 보고서를 **수 분 내에 초안 수준으로 자동 생성**하여, 담당자는 검증과 보완에만 집중할 수 있도록 설계되었습니다.

## 💡 핵심 가치

| 기존 방식 | 본 시스템 |
|-----------|-----------|
| 담당자가 타 지자체 사례를 일일이 검색 | Tavily API로 실시간 자동 수집 |
| 관련 법령을 국가법령정보센터에서 수동 확인 | 법령 API 연동 자동 검색 + 원문 링크 |
| 의회 예상 질의를 경험에 의존해 작성 | AI가 예산·중복·효과성 관점에서 자동 도출 |
| 보고서 양식을 매번 새로 작성 | 표준화된 6개 섹션 표 형식 자동 생성 |
| 작성 소요 시간: 수 시간 ~ 수일 | **초안 생성: 약 1~2분** |

## ⚙️ 주요 기능

- **사업 정보 입력 폼** — 사업명·유형·대상·예산·기간·내용 (입력값 검증 포함)
- **AI 보고서 자동 생성** — Claude API 기반 6개 섹션 병렬 생성
- **사전 검토 체크리스트 자동 판단** — 보안성 검토·개인정보 영향평가·지방재정투자심사·의회 의결 등 8개 항목을 입력값 기반으로 AI가 해당/불해당 자동 분류
- **담당자 위험도 체크리스트** — 12개 항목 점수 기반 위험도 자동 산정 (저/중/고), AJAX 실시간 저장
- **타 지자체 유사 사례 실시간 검색** — Tavily API 연동
- **관련 법령 자동 검색** — 국가법령정보센터 API 연동, 법령 원문 바로가기 링크 제공
- **생성 이력 관리** — SQLite 저장·조회·상세보기
- **문서 다운로드** — Word(.docx) 표 형식 다운로드 / 인쇄(PDF) 저장
- **단일 실행파일 배포** — PyInstaller 패키징으로 Python 미설치 PC에서도 더블클릭 실행

## 🚀 개발 과정 (POC → 고도화)

> 본 프로젝트는 **Claude Code(AI 코딩 에이전트)와의 협업**으로 개발되었습니다.
> 하루짜리 행정혁신 교육 POC로 시작하여 단계적으로 고도화했습니다.

### 1단계 — 기본 구조 구축
- Claude Code로 Flask + SQLite 기반 앱 골격 구현
- 섹션별 프롬프트 설계 및 Claude API 병렬 호출 구조 적용
- **허위 법령 조문·허위 지자체 사례 단정 금지 원칙**을 프롬프트에 명시

### 2단계 — 보고서 구조 개선 (실무 피드백 반영)
- 초기 9개 항목 → **6개 섹션으로 축소** (실무 활용도 중심 재구성)
- 줄글 형식 → **표 형식 전환**으로 가독성 개선
- 웹 화면 **카드형 UI**(섹션별 펼치기/접기) 적용
- **사전 검토 체크리스트** 신설 — 보안성 검토·개인정보 영향평가·지방재정투자심사·의회 의결·환경/안전영향평가 등 8개 항목을 AI가 자동 판단
- **담당자 위험도 체크리스트** 신설 — 예산·사업 성격·추진 역량·의회 리스크 4개 영역 12개 항목, 점수 기반 위험도 자동 산정

### 3단계 — 외부 데이터 실시간 연동
- **Tavily API** 연동 → 타 지자체 유사 사례 실시간 검색, AI 학습 데이터 한계 보완
- **국가법령정보센터 API** 연동 → 관련 법령 자동 검색, 법령 원문 바로가기 링크 제공
- API 장애 시 "담당자 직접 확인 필요" 표시로 fallback 처리 (앱 중단 없음)

### 4단계 — 배포 방식 개선 (내부망 환경 대응)
- **Word(.docx) 표 형식 다운로드** — python-docx로 표를 직접 생성하여 문서에서도 표 구조 유지
- **PyInstaller 단일 실행파일(.exe) 패키징**
  - 더블클릭 → Flask 서버 백그라운드 자동 구동 → 브라우저 자동 실행
  - API 키 최초 1회 입력 후 로컬 저장 (key_store.py)
  - Python 미설치 PC에서도 즉시 사용 가능

## 📦 설치 및 실행

### 1. 저장소 클론

```bash
git clone https://github.com/hyewon000/jeju-ai.git
cd jeju-ai
```

### 2. 가상환경 생성 및 의존성 설치

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

### 3. 환경변수 설정

```bash
# Windows
copy .env.example .env

# macOS / Linux
cp .env.example .env
```

`.env` 파일을 열어 API 키를 입력합니다. (아래 [환경변수 목록](#-환경변수-목록) 참고)

### 4. 앱 실행

```bash
python app.py
```

브라우저에서 `http://localhost:5000` 접속

## 💾 실행파일(.exe) 사용 방법

Python 환경이 없는 사용자도 빌드된 실행파일로 바로 사용할 수 있습니다.

1. `dist/` 폴더의 `정책사업보고서.exe` 더블클릭
2. 최초 실행 시 API 키 입력 화면에서 키 등록 (이후 자동 저장)
3. 브라우저가 자동으로 열리며 바로 사용

> ⚠️ 최초 실행 시 Windows SmartScreen 경고가 표시될 수 있습니다.
> 코드 서명이 없는 자체 빌드 파일이기 때문이며, "추가 정보 → 실행"으로 진행할 수 있습니다.

### 직접 빌드하려면

```bash
build.bat
```

## 🛡️ AI 신뢰성 확보 원칙

공공기관 내부 검토자료 특성을 고려해 다음 원칙을 시스템 전반에 적용했습니다.

1. **허위 사실 단정 금지** — 확인되지 않은 지자체 사례·법령 조문 번호를 AI가 임의로 생성하지 않도록 프롬프트에 명시
2. **출처 기반 작성** — 타 지자체 사례는 Tavily 실시간 검색 결과, 법령은 법령 API 검색 결과만 사용
3. **불확실성 명시** — 확인이 필요한 항목은 "확인 필요", "담당자 직접 확인 필요", "~로 판단됨" 등 공문서형 유보 표현 사용
4. **AI 초안 고지** — 모든 보고서 하단에 "Claude AI 자동 생성 초안, 담당자 직접 확인 필요" 문구 표기
5. **담당자 검증 구조** — AI 예상 판단과 별도로 담당자 실제 체크란·비고란을 두어 사람의 최종 검토를 전제로 설계
